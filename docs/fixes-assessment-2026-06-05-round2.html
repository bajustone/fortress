Newly Confirmed Fixes

1. Atomic OAuth consent approval

handleApproveFlow now claims usedAt IS NULL, mints the code, and deletes the flow in one transaction. A concurrency test proves exactly one approval succeeds.

2. Refresh concurrency decision/tests

Strict replay semantics are documented and covered for core auth and OAuth refresh. Core family revocation now commits before throwing TOKEN_REUSE.

3. Exact CSRF documentation

Docs now state that access or refresh cookies trigger CSRF checks, even with Authorization/API-key headers; pure bearer/API-key requests without cookies skip.

4. SQLite nested transactions

The SQLite adapter detects active transaction context and rejects nested transactions clearly instead of queueing into a deadlock.

5. SQLite multi-row updates

SQLite UPDATE ... RETURNING now consumes all returned rows, preserving multi-row revocation correctness while returning one row/null.

6. Data-isolation runtime docs

The Node/Bun node:async_hooks requirement for bypass helpers is documented in README and plugin docs.

7. Follow-up tests added

API-key self-management negative tests now cover GET, DELETE, rotate; IAM tests cover permission identity by effect and conditions.

8. OIDC refresh id_token

Refresh-token responses now include a fresh id_token when the token family scope includes openid.

Remaining High-Importance Issue

Critical if used Tenancy plugin remains unsafe if mounted

File: src/plugins/tenancy/index.ts

This was intentionally excluded from the remediation pass. It should remain experimental/unmounted until hardened or removed from production-facing surfaces.

  • CREATE SCHEMA IF NOT EXISTS ${schemaName} interpolates an identifier derived from taxId.
  • SET LOCAL search_path TO ${schemaName}, public interpolates an identifier derived from tenant code/header context.
  • SET LOCAL is executed separately before CRUD; outside a transaction it can silently fail open to public.
  • Tenant code is request/header-derived unless a trusted resolution layer wraps it.

Required before production use: validated/quoted identifiers, transaction-pinned search-path changes, authenticated tenant resolution, or export/doc removal until hardened.
